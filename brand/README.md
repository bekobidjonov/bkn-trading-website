# BKN Trading — Logo

| File | Use |
|---|---|
| `bkn-logo-horizontal` | Main logo — website header, letterhead, invoices, email signature |
| `bkn-logo-horizontal-dark` | Same, on navy background |
| `bkn-logo-stacked` / `-dark` | Square-ish spaces — flyers, banners, car window stickers |
| `bkn-mark` | Monogram only (transparent) |
| `bkn-icon-navy` | Instagram / Facebook / WhatsApp profile picture (1080×1080) |
| `bkn-icon-white` | Profile picture, light version |
| `bkn-favicon` | Browser tab icon |

`svg/` = vector (any size, for printing/signage). `png/` = high-resolution images with transparent backgrounds.

**Colours** — Navy `#0E1A2B` · Gold `#A8844A` · White `#FFFFFF`
**Typeface** — Cormorant Garamond SemiBold (SIL Open Font License), letters converted to outlines.
**Idea** — The gold line under "BKN" is the route a car takes: bought in Japan, then rising up and out to the world (export).
